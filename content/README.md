## Content Licensing

Educational content **is not** covered by the code license (AGPL-3.0). Each file in the frontmatter specifies the origin (`provenance`), source line (`author`) and license (`license`, SPDX identifier).

| `provenance`   | What it is                                                      | License                                                                                 |
| -------------- | --------------------------------------------------------------- | --------------------------------------------------------------------------------------- |
| `human`        | Text written by a human, rights belong to the author or project | **CC-BY-4.0** (project policy)                                                          |
| `ai-assisted`  | Significant creative contribution by a human, AI as a tool      | **CC-BY-4.0**, in `author` — human author                                               |
| `ai-generated` | Fully generated by AI, without creative contribution by a human | **CC0-1.0** is mandatory — import will reject other licenses                            |
| `third-party`  | Foreign material                                                | License of the source, compatible with open distribution; in `author` — author and link |

Why CC0 for AI texts: a fully generated text has no human author, and in many jurisdictions, no copyright arises over it. The project does not claim non-existent exclusive rights; CC0 means relinquishing rights to the extent that they may exist at all.

## Text Format

```markdown
---
slug: b1-example-text # unique, kebab-case
title: Example Text
level: B1 # A1 | A2 | B1 | B2 | C1 | C2
summary: One or two sentences for the library card.
topics: [travel, culture]
author: Your Name
provenance: human # human | ai-assisted | ai-generated | third-party
license: CC-BY-4.0 # SPDX identifier; for ai-generated — only CC0-1.0
glossary: # optional; works without AI
  - term: look forward to
    partOfSpeech: phrasal verb
    definition: to feel happy about something that is going to happen
    example: I'm looking forward to the trip.
---

First paragraph. Lines within a paragraph are joined together.

Paragraphs are separated by a blank line. HTML is prohibited.
```

## Import

```bash
pnpm content:import
```

The command imports texts from `reading/` and grammar from `grammar/`. Import is idempotent: unchanged files are skipped (SHA-256 is compared), modified files are updated together with the glossary in one transaction. Deleted files **are not** deleted from the database, because saved words refer to the texts.

Bundled glossaries use English definitions and examples. The optional `translation` field can be omitted; AI explanations can still include translations in the native language selected in the learner's profile.

## Grammar Topic Format

Topics are stored in `grammar/`. Explanations, examples and exercises are written in English.

```markdown
---
slug: a1-verb-to-be
title: 'Verb to be: am, is, are'
level: A1
summary: One or two phrases for the topic card.
author: Your Name
provenance: human # human | ai-assisted | ai-generated | third-party
license: CC-BY-4.0 # for ai-generated — only CC0-1.0
exercises:
  - type: choice # choose one option
    prompt: 'I ___ a student.' # exactly one gap ___
    options: [am, is, are]
    answer: am # must be among options
    explanation: 'Am is always used with the pronoun I.'
  - type: gap # input answer
    prompt: 'We ___ (not / be) tired.'
    answers: ["aren't", 'are not'] # all acceptable answers
    explanation: 'Negation: are + not.'
---

## Section Title

Paragraph. **Bold** highlights the key.

- list item

> Example in English.
```

Only headers `##`, paragraphs, lists `- ` and examples `> ` are supported; HTML is prohibited. Answers are compared case-insensitively, without extra spaces or punctuation at the edges, and the typographic apostrophe is considered equal to `'`. Edits to titles, rules or explanations preserve exercise IDs and learner attempts. Changing prompts, kinds, options or accepted answers replaces the exercises and removes attempts that no longer match them.

All 10 topics in `grammar/` were generated by an AI assistant (Anthropic Claude) in October 2026, so they have `provenance: ai-generated` and `CC0-1.0`.

## Personal AI Texts

Texts that a user creates on the "My Texts" page do not end up in `content/` or the public library: they are stored in the database with the owner, are visible only to them, and are deleted along with the account. They are automatically assigned `provenance: ai-generated` and `CC0-1.0`.
