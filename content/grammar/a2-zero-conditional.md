## Meaning and use

Use a general conditional to describe a regular relationship: if a condition happens, a result normally follows. The common teaching pattern called the zero conditional uses present simple in both clauses. It is useful for routines, instructions, and general truths, but does not guarantee a scientific law. When can replace if when the speaker presents the condition as an expected occurrence rather than an uncertainty.

## Forms and sentence patterns

- If + present simple, present simple.
- Present simple + if + present simple.
- If + present simple, imperative for an instruction.
- Use a comma after an initial if clause; usually omit it when the if clause comes last.

## Examples in context

> If I skip breakfast, I feel hungry before noon.
> Water expands when it freezes.
> If the screen goes dark, press this button.

## Common mistakes and important distinctions

Do not assume all if sentences are about the future. A general result often uses a present form in both clauses. An instruction can use an imperative rather than a statement. If and when have related but different implications. Compare the first conditional when discussing one realistic future situation instead of a repeated relationship.
