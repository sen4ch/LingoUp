# LingoUp grammar reference

100 original English-language lessons cover the core learner grammar of A1-C2, with 420 exercises. Level labels are suggested study stages, not an official exhaustive CEFR grammar syllabus. Topics overlap levels; advanced chapters revisit earlier patterns with greater precision.

The reference includes sentence structure, nouns, determiners, pronouns, adjectives, adverbs, prepositions, questions, negation, verb patterns, tense/aspect, modality, conditionals, relative and other clauses, passive voice, reporting, discourse and regional/register variation. Dedicated appendices cover irregular verb forms, twelve common tense/aspect patterns, punctuation, and terminology. It is a practical learner reference, not an assertion that every dialect feature or linguistic analysis is exhausted.

All newly written explanations, examples, and exercises are independently AI-generated for this project and released under CC0-1.0. Further-reading links do not imply that the linked publishers endorse this project or release their content under CC0. No publisher exercise sets or explanatory passages are reproduced. The ten original exercise sets retain their prompts and accepted answers so that existing exercise IDs and attempts survive the import. Their explanations have been expanded.

## Maintenance

Markdown lessons are the content source of truth. Their frontmatter is validated by parseGrammarDocument before import. Update apps/web/src/lib/grammar-reference.ts when adding or recategorising a lesson; it supplies navigation and study order, not answer keys. Only the API stores accepted answers; public lesson responses omit them. Run the content import after editing lessons. Existing exercise identities remain stable when only explanatory blocks change.
