## Meaning and use

Conditional relationships can be expressed without ordinary if. Unless usually means if not, provided that and as long as set a requirement, and even if stresses that the result holds despite a possible condition. In case describes a precaution taken because something might happen; it is not generally interchangeable with if. Supposing and what if can introduce imagined possibilities in discussion.

## Forms and sentence patterns

- Unless = if not in many exclusion conditions.
- Provided (that)/as long as + clause establishes a condition.
- In case + clause motivates a precaution.
- Even if + clause says that a possible condition does not alter the main result.

## Examples in context

> Take a charger in case the battery runs out.
> You can borrow the car as long as you return it tonight.
> We will go for a walk even if it rains.

## Common mistakes and important distinctions

Do not normally add another negative after unless when the intended meaning is simply if not. In case asks you to prepare now for a possible later problem; if can make the action depend on the condition actually occurring. Unless can be unsuitable when it changes the logic of a particular counterfactual sentence. Check the meaning, not just a memorised replacement.
