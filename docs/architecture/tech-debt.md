# Технический долг и ограничения MVP

Список честный: всё перечисленное **не реализовано** или реализовано упрощённо. Приоритет: 🔴 важно до публичного запуска, 🟡 желательно, ⚪ по мере роста.

## Безопасность и приватность

|     | Пункт                                                                                         | Комментарий                                                                                                                                                          |
| --- | --------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 🔴  | Нет подтверждения email и восстановления пароля                                               | Нужен опциональный SMTP-адаптер. Пока забытый пароль = потерянный аккаунт                                                                                            |
| 🔴  | Регистрация раскрывает, что email уже занят (409)                                             | Приемлемо без подтверждения email; после его появления отвечать одинаково                                                                                            |
| 🔴  | Лимиты по IP зависят от корректного `X-Forwarded-For`                                         | Next.js не перезаписывает клиентский заголовок. В production нужен reverse proxy, перезаписывающий его (см. operations.md). Вход дополнительно ограничен по аккаунту |
| 🟡  | Блокировка входа по аккаунту может быть использована для временной блокировки чужого аккаунта | 15 минут после 10 неудачных попыток; нужны CAPTCHA или подтверждение по email                                                                                        |
| 🟡  | Пароль Valkey передаётся аргументом `--requirepass`                                           | Виден в `docker inspect` и списке процессов контейнера; лучше конфиг-файл или Docker secrets                                                                         |
| 🟡  | Базовые образы закреплены по тегу, а не по digest                                             | Для воспроизводимости и защиты от подмены тега закрепить `@sha256:…`                                                                                                 |
| 🟡  | CSP разрешает `'unsafe-inline'` для скриптов                                                  | Нужен nonce-based CSP в Next.js (middleware/proxy)                                                                                                                   |
| 🟡  | Нет журнала аудита (входы, удаление аккаунта, экспорт)                                        |                                                                                                                                                                      |
| 🟡  | Сессии без ротации токена и без списка устройств в UI                                         | Таблица хранит данные; нет UI «выйти на всех устройствах»                                                                                                            |
| ⚪  | Swagger UI включён по умолчанию                                                               | Выключать в production: `SWAGGER_ENABLED=false`                                                                                                                      |

## Функциональность

|     | Пункт                                                                                                                                     | Комментарий                                                                                                                                       |
| --- | ----------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------- |
| 🟡  | Lookup без AI работает только для слов из глоссария текста                                                                                | Нужен встроенный открытый словарь (проверка лицензии Wiktionary/WordNet)                                                                          |
| 🟡  | Сохранённые слова не подсвечиваются в публичных текстах                                                                                   | В личных AI-текстах подчёркнуты слова, под которые текст создан; API отдаёт `savedWordId` только при lookup                                       |
| 🟡  | Нет UI редактирования слова                                                                                                               | `PATCH /v1/vocabulary/words/:id` реализован                                                                                                       |
| 🟡  | День активности считается в UTC                                                                                                           | Нужен часовой пояс в настройках и в payload событий                                                                                               |
| 🟡  | Параметры FSRS — по умолчанию, без персональной оптимизации                                                                               | История повторений хранится полностью; оптимизатор можно добавить позже                                                                           |
| ⚪  | Один язык интерфейса (русский)                                                                                                            | Строки вынесены в `apps/web/src/i18n`, переключение языка не реализовано                                                                          |
| ⚪  | PWA не реализовано                                                                                                                        | Нет manifest и service worker                                                                                                                     |
| ⚪  | Streaming AI-ответов не реализован                                                                                                        | Не нужен для `WordExplanation`                                                                                                                    |
| ⚪  | Объявлены, но не реализованы AI-задачи: GrammarExplanation, WritingAssessment, SpeechRecognition, SpeechSynthesis, LearningRecommendation | Gateway отвечает `not_supported`                                                                                                                  |
| 🟡  | AI-генерация текстов и упражнений синхронная                                                                                              | Запрос держится до `AI_GENERATION_TIMEOUT_MS` (120 с). Для медленных моделей перенести в worker с опросом статуса (ADR-0008)                      |
| 🟡  | Озвучка зависит от серверов Microsoft                                                                                                     | Режим `edge` неофициальный и может перестать работать; для произношения запасной вариант — голос браузера; аудирование использует локальный Piper |
| 🟡  | Поиск картинок в Wikimedia Commons без фильтра взрослого контента                                                                         | Поиск запускает сам пользователь; у Openverse фильтр есть, но API нестабилен                                                                      |
| ⚪  | Нет генерации картинок                                                                                                                    | Локальный Stable Diffusion требует ~7 ГБ и делит видеопамять с LLM; можно добавить как ещё один источник                                          |
| ⚪  | Картинки хранятся в PostgreSQL                                                                                                            | ~30–60 КБ на слово; при росте — объектное хранилище (S3-совместимое)                                                                              |
| ⚪  | Кэш аудио в Valkey не ограничен по объёму                                                                                                 | Слово ~10 КБ, предложение до ~150 КБ; при росте нужен `maxmemory-policy` или хранилище файлов                                                     |
| 🟡  | Нет модерации AI-вывода                                                                                                                   | Проверяются структура и наличие слов; личный текст видит только его владелец                                                                      |
| 🟡  | Упражнение по словам — самопроверка                                                                                                       | Ответы приходят клиенту; подделка результата влияет только на собственную статистику                                                              |
| ⚪  | Формы слов распознаются только для регулярных окончаний                                                                                   | improve → improved распознаётся, buy → bought — нет                                                                                               |
| ⚪  | Ошибки в грамматике не возвращаются на повторение                                                                                         | Нет связи упражнений с FSRS                                                                                                                       |
| ⚪  | События LessonStarted, AssessmentCompleted, SkillLevelUpdated, LearningPlanUpdated — только контракты                                     | Нет производителей                                                                                                                                |
| ⚪  | Модули Assessment, Planner, Media не реализованы                                                                                          | См. ROADMAP.md                                                                                                                                    |

## Инфраструктура и наблюдаемость

|     | Пункт                                                  | Комментарий                                                          |
| --- | ------------------------------------------------------ | -------------------------------------------------------------------- |
| 🟡  | Нет OpenTelemetry и метрик Prometheus                  | Есть структурированные логи с request id и health checks             |
| 🟡  | Нет мониторинга failed-задач BullMQ                    | Задачи с исчерпанными попытками хранятся 7 дней; нужен алерт/дашборд |
| 🟡  | Пул PostgreSQL на процесс задаётся вручную             | При масштабировании нужен PgBouncer                                  |
| ⚪  | Кэш сессий в Valkey не реализован                      | Сейчас один индексный запрос в PostgreSQL на каждый запрос           |
| ⚪  | Кэш AI-ответов не реализован                           | Одинаковые lookup повторно вызывают модель                           |
| ⚪  | Миграции запускаются отдельным сервисом без блокировки | Не запускайте `migrate` параллельно на нескольких хостах             |

## Качество

|     | Пункт                                                           | Комментарий                                                                 |
| --- | --------------------------------------------------------------- | --------------------------------------------------------------------------- |
| 🟡  | Нет unit-тестов React-компонентов                               | Логика выделения вынесена в `selection.ts` и покрыта тестами; UI покрыт E2E |
| 🟡  | Pydantic-схемы ai-service дублируют TS-контракты вручную        | Можно генерировать из JSON Schema (`z.toJSONSchema`)                        |
| ⚪  | TypeScript 6 вместо 7                                           | TS 7 пока не поддерживают typescript-eslint и @nestjs/swagger (ADR-0002)    |
| ⚪  | ESLint 9 вместо 10                                              | Плагины eslint-config-next пока не поддерживают ESLint 10                   |
| ⚪  | `fastapi.testclient` выдаёт DeprecationWarning (httpx → httpx2) | Предупреждение в зависимости, не в нашем коде                               |
| ⚪  | Лицензия кода не выбрана                                        | Решение владельца, ADR-0007                                                 |
