# ADR-0007: Лицензия исходного кода — MIT или AGPL-3.0

- Статус: **принято** (2026-10-27): **AGPL-3.0-only** для исходного кода. Решение владельца проекта.

> Выбран идентификатор `AGPL-3.0-only`, а не `-or-later`: формулировка решения — «AGPL-3.0», и права на будущие версии лицензии FSF не предоставляются заранее. Смена на `-or-later` возможна в будущем, пока все правообладатели согласны.

- Дата: 2026-10-26

Полный текст лицензии — в `LICENSE` (без изменений, с gnu.org).

## Сравнение

| Критерий                                  | MIT                                                           | AGPL-3.0                                                |
| ----------------------------------------- | ------------------------------------------------------------- | ------------------------------------------------------- |
| Порог входа для контрибьюторов и компаний | Минимальный                                                   | Выше: многие компании запрещают AGPL внутри             |
| Защита от закрытого SaaS-форка            | Нет: можно взять код, улучшить и закрыто продавать как сервис | Да: изменённую версию, доступную по сети, нужно открыть |
| Совместимость с зависимостями             | Совместима со всем стеком                                     | Совместима (все текущие зависимости — MIT/Apache/BSD)   |
| Возможность двойного лицензирования       | Не нужна                                                      | Возможна (AGPL + коммерческая), но потребует CLA        |
| Типичные примеры                          | Большинство библиотек                                         | Mastodon, Plausible, Grafana (с 2021)                   |

## Рекомендация

- Если приоритет — **сообщество платформы и защита от закрытых SaaS-клонов** (продукт, а не библиотека): **AGPL-3.0** для `apps/*`.
- Если приоритет — **максимальное распространение и встраивание**: **MIT**.
- Возможен гибрид: `packages/*` (contracts, learning-engine, ui) под MIT, приложения `apps/*` под AGPL-3.0.

## Отдельно лицензируются

- **Учебный контент** (`content/`): решение владельца (2026-10-27) — CC BY 4.0 для контента, на который у проекта есть права; полностью AI-сгенерированные материалы публикуются под CC0-1.0 без заявления исключительных прав. Правило проверяется при импорте (поле `provenance`), подробности — в `content/README.md`.
- **AI-модели**: лицензии моделей Ollama/vLLM проверяются отдельно (например, Llama Community License ограничивает использование). Проект не распространяет веса моделей.
