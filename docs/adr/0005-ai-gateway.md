# ADR-0005: AI Gateway, адаптеры провайдеров и приватность

- Статус: принято
- Дата: 2026-10-26

## Контекст

AI должен быть опциональным, без обязательного GPU и платных API. Модели будут меняться, а пользовательский контент нельзя отправлять третьим сторонам без явной настройки.

## Решение

- В API есть модуль `AI Gateway` с портом `AIProvider` (`supports(task)`, `execute(task, signal)`, `dataLocality`).
- Адаптеры: `MockAIProvider` (детерминированный, in-process, явно помечает ответы как `provider: "mock"`) и `AiServiceProvider` (HTTP к `apps/ai-service` с сервисным токеном).
- `apps/ai-service` содержит собственные адаптеры: `mock`, `ollama`, `openai-compatible` (vLLM, LocalAI, любой совместимый API пользователя).
- Gateway применяет: таймаут, семафор параллельности, retry только для идемпотентных задач, Zod-валидацию вывода, дневную квоту на пользователя.
- Внешний провайдер используется только при `AI_ALLOW_EXTERNAL=true` **и** согласии пользователя (`ai_data_sharing`). По умолчанию согласие выключено.
- Базовый функционал работает без AI: карточка слова строится из глоссария текста, а AI лишь дополняет её.

## Последствия

- Новая модель подключается адаптером без изменения бизнес-модулей.
- `MockAIProvider` не притворяется настоящим AI: UI показывает, что объяснение сгенерировано заглушкой.
