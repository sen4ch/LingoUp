# ADR-0005: AI Gateway, Providers Adapters and Privacy

- Status: Accepted
- Date: 2026-10-26

## Context

AI should be optional, without mandatory GPU and paid APIs. Models will change, and user content cannot be sent to third parties without explicit configuration.

## Solution

- The API has a module `AI Gateway` with port `AIProvider` (`supports(task)`, `execute(task, signal)`, `dataLocality`).
- Adapters: `MockAIProvider` (deterministic, in-process, explicitly marks responses as `provider: "mock"`) and `AiServiceProvider` (HTTP to `apps/ai-service` with service token).
- `apps/ai-service` contains its own adapters: `mock`, `ollama`, `openai-compatible` (vLLM, LocalAI, any user-compatible API).
- Gateway applies: timeout, parallelism semaphore, retry only for idempotent tasks, Zod-validation of output, daily quota per user.
- External provider is used only when `AI_ALLOW_EXTERNAL=true` **and** user consent (`ai_data_sharing`). By default, consent is disabled.
- Basic functionality works without AI: word card is built from text glossary, and AI only supplements it.

## Implications

- New model is connected via adapter without changing business modules.
- `MockAIProvider` does not pretend to be real AI: UI shows that the explanation is generated by the mock.
